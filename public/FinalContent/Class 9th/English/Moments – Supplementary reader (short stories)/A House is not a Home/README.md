# A House Is Not a Home - Interactive English Lesson

## Overview
This is an interactive English lesson based on the story "A House Is Not a Home" by Zan Gaudioso. It provides a digital, engaging experience for students to explore the text, answer comprehension questions, and engage with vocabulary and language exercises.

## Features
- **Interactive Text Reading**: Read the story with audio narration support
- **Vocabulary Highlighting**: Key vocabulary words are highlighted with definitions
- **Comprehension Questions**: Multiple formats of questions to test understanding
- **Language Activities**: Grammar and vocabulary exercises
- **Progress Tracking**: Track completion of modules and overall score
- **Audio Narration**: British female voice narration of content (requires browser with speech synthesis support)
- **Mobile-Friendly Design**: Optimized for all device sizes

## Technical Requirements
- Modern web browser (Chrome, Firefox, Safari, or Edge recommended)
- JavaScript enabled
- For full experience, a browser with Speech Synthesis API support

## Structure
- `index.html` - Main HTML file
- `css/styles.css` - Styling for the lesson
- `js/main.js` - Core functionality 
- `js/a-house-is-not-a-home-story.js` - Story content and narration functionality
- `js/questions.js` - Reading comprehension questions
- `js/activities.js` - Interactive activities and exercises

## Using the Lesson
1. Open `index.html` in a web browser
2. Navigate through modules using the top navigation bar
3. Enable audio narration with the speaker button in the bottom-right corner
4. Track progress using the progress bar at the top of the page

## Local Development
To run this lesson locally:
1. Clone or download the repository
2. Run a local web server in the lesson directory 
3. Open `http://localhost:PORT` in your browser (where PORT is your server port)

Simple local server example:
```
node simple_server.js
```

## Notes for Educators
- The lesson is designed to be used in a classroom setting or for independent study
- The content aligns with the Class IX English curriculum
- Exercises focus on reading comprehension, vocabulary development, and language skills
- The audio narration feature can help students with diverse learning needs
