# रैदास के पद - इंटरैक्टिव हिंदी पाठ

## परिचय

यह एक इंटरैक्टिव हिंदी पाठ मॉड्यूल है जो संत रैदास के पदों पर आधारित है। यह मॉड्यूल विद्यार्थियों को रैदास के जीवन और उनके पदों के माध्यम से हिंदी साहित्य की संत काव्य परंपरा से परिचित कराता है।

## विशेषताएँ

- संत रैदास का जीवन परिचय
- रैदास के दो प्रसिद्ध पदों का अध्ययन
- इंटरैक्टिव प्रश्न और अभ्यास
- श्रवण, वाचन और लेखन गतिविधियाँ
- मूल्यांकन और फीडबैक प्रणाली
- वाचन सहायता (टेक्स्ट-टू-स्पीच)

## तकनीकी विवरण

इस मॉड्यूल में निम्नलिखित तकनीकों का उपयोग किया गया है:

- HTML5, CSS3 और JavaScript
- मोबाइल-अनुकूल डिज़ाइन
- Web Speech API (वाचन के लिए)
- इंटरैक्टिव फॉर्म एलिमेंट्स

## इस्तेमाल करने के लिए

1. पूरे फ़ोल्डर को अपने वेब सर्वर पर अपलोड करें या Node.js के साथ स्थानीय रूप से चलाएं
2. Node.js के साथ स्थानीय सर्वर शुरू करने के लिए: `node simple_server.js` चलाएँ
3. अपने ब्राउज़र में `http://localhost:8080` पर जाएँ

## क्रेडिट्स

इस मॉड्यूल की रचना हिंदी साहित्य के शिक्षकों और शिक्षार्थियों के लिए एक शिक्षण संसाधन के रूप में की गई है।
