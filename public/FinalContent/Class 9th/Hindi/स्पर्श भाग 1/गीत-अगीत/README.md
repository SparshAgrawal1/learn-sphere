# गीत-अगीत - इंटरैक्टिव हिंदी पाठ

रामधारी सिंह दिनकर की कविता 'गीत-अगीत' पर आधारित इंटरैक्टिव डिजिटल लर्निंग मॉड्यूल।

## विवरण

यह मॉड्यूल कक्षा 8 के हिंदी पाठ्यक्रम के अध्याय 8 "गीत-अगीत" के लिए तैयार किया गया है। इसमें निम्नलिखित खंड शामिल हैं:

1. **लेखक परिचय** - रामधारी सिंह दिनकर का जीवन परिचय
2. **पाठ प्रवेश** - कविता का परिचय और मुख्य भाव
3. **कविता** - पूरी कविता 'गीत-अगीत' के साथ शब्दार्थ
4. **प्रश्न अभ्यास** - कविता पर आधारित प्रश्न और उत्तर
5. **भाषा अध्ययन** - शब्दार्थ और प्रचलित रूप
6. **गतिविधियाँ** - विभिन्न इंटरैक्टिव गतिविधियाँ

## सुविधाएँ

- 🔊 **वाचन सुविधा** - सभी पाठ को सुनने की सुविधा
- 📱 **रिस्पॉन्सिव डिज़ाइन** - सभी डिवाइस पर काम करता है
- 🎯 **इंटरैक्टिव गतिविधियाँ** - सीखने को रोचक बनाने के लिए
- 📊 **प्रगति ट्रैकिंग** - सीखने की प्रगति को देखने के लिए
- 🖨️ **प्रिंट सुविधा** - पाठ को प्रिंट करने के लिए

## स्थापना

1. सभी फाइलों को एक फोल्डर में डाउनलोड करें
2. Node.js स्थापित करें (यदि नहीं है)
3. टर्मिनल में निम्नलिखित कमांड चलाएं:

```bash
node simple_server.js
```

4. ब्राउज़र में `http://localhost:3000` खोलें

## उपयोग

1. **नेविगेशन** - ऊपर के मेनू से अलग-अलग खंडों में जाएं
2. **वाचन** - 🔊 बटन दबाकर पाठ सुनें
3. **अभ्यास** - प्रश्नों के उत्तर दें और अपनी प्रगति देखें
4. **गतिविधियाँ** - विभिन्न इंटरैक्टिव गतिविधियों में भाग लें
