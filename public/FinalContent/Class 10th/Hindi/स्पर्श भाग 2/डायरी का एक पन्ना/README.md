# डायरी का एक पन्ना - इंटरैक्टिव हिंदी पाठ

## परिचय

यह एक इंटरैक्टिव हिंदी पाठ है जो "डायरी का एक पन्ना" (26 जनवरी 1931) पर आधारित है। यह पाठ सीताराम सेकसरिया द्वारा लिखित है और स्वतंत्रता आंदोलन के दौरान की घटनाओं को दर्शाता है।

## विशेषताएं

### 🎯 मुख्य विशेषताएं
- **इंटरैक्टिव नेविगेशन**: 6 मॉड्यूल के साथ संरचित पाठ
- **वाचन सुविधा**: वेब स्पीच API के साथ हिंदी वाचन
- **प्रगति ट्रैकिंग**: स्कोर और समय ट्रैकिंग
- **प्रश्नोत्तर**: बहुविकल्पीय प्रश्न और उत्तर
- **भाषा अध्ययन**: शब्दार्थ, व्याकरण और अभ्यास
- **गतिविधियां**: सुनना, बोलना, लिखना और प्रोजेक्ट कार्य

### 🎨 डिज़ाइन विशेषताएं
- **रिस्पॉन्सिव डिज़ाइन**: सभी डिवाइस पर काम करता है
- **हिंदी फॉन्ट**: Noto Sans Devanagari फॉन्ट का उपयोग
- **एनिमेशन**: सुंदर ट्रांजिशन और एनिमेशन
- **एक्सेसिबिलिटी**: ARIA लेबल और कीबोर्ड नेविगेशन

## फ़ाइल संरचना

```
डायरी का एक पन्ना/
├── index.html              # मुख्य HTML फ़ाइल

├── README.md              # यह फ़ाइल
├── css/                   # CSS फ़ाइलें
│   ├── styles.css         # मुख्य स्टाइल

│   ├── improved-form-elements.css # फॉर्म एलिमेंट्स
│   ├── choice-forms.css   # चॉइस फॉर्म्स
│   └── feedback-styles.css # फीडबैक स्टाइल्स
└── js/                    # JavaScript फ़ाइलें
    ├── main.js            # मुख्य JavaScript
    ├── story.js           # कहानी कंटेंट
    ├── questions.js       # प्रश्न और उत्तर
    ├── activity-answers.js # गतिविधि उत्तर

    ├── form-enhancements.js # फॉर्म एन्हांसमेंट
    └── language-exercises.js # भाषा अभ्यास
```

## स्थापना और चलाना

### आवश्यकताएं
- Node.js (संस्करण 12 या उच्चतर)
- आधुनिक वेब ब्राउज़र (Chrome, Firefox, Safari, Edge)

### स्थापना
1. इस फ़ोल्डर को डाउनलोड करें
2. टर्मिनल/कमांड प्रॉम्प्ट खोलें
3. फ़ोल्डर में जाएं:
   ```bash
   cd "डायरी का एक पन्ना"
   ```

### सर्वर चलाना
```bash
node simple_server.js
```

### ब्राउज़र में खोलना
सर्वर चलने के बाद, ब्राउज़र में जाएं:
```
http://localhost:3000
```
