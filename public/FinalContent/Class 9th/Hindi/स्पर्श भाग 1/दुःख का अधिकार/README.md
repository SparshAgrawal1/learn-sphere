# दुःख का अधिकार - इंटरैक्टिव हिंदी पाठ

यह एक इंटरैक्टिव हिंदी पाठ मॉड्यूल है जो यशपाल की कहानी "दुःख का अधिकार" पर आधारित है। यह कक्षा 9वीं के छात्रों के लिए तैयार किया गया है।

## 📚 विषयवस्तु

### कहानी का परिचय
"दुःख का अधिकार" यशपाल द्वारा लिखित एक प्रभावशाली कहानी है जो समाज में व्याप्त असमानता, अंधविश्वास और सामाजिक भेदभाव को उजागर करती है। कहानी बताती है कि दुःख की अनुभूति सभी को समान रूप से होती है, परंतु गरीबों को दुःख मनाने का अधिकार और अवकाश भी नहीं मिलता।

### लेखक परिचय
**यशपाल (1903-1976)**
- जन्म: फिरोजपुर छावनी
- शिक्षा: लाहौर में उच्च शिक्षा
- पृष्ठभूमि: क्रांतिकारी गतिविधियों में सक्रिय, भगत सिंह के साथ स्वतंत्रता आंदोलन में भाग
- प्रमुख कृतियाँ: "तेरी, मेरी, उसकी बात" (साहित्य अकादेमी पुरस्कार), "झूठा सच", "दादा कामरेड"
- दर्शन: सामाजिक और आर्थिक समानता

### 2. 📝 लेखक परिचय

- साहित्यिक दर्शन और शैली

- **शब्दार्थ**: कठिन शब्दों के अर्थ और संदर्भ

### 4. ❓ प्रश्न अभ्यास

- **लिखित प्रश्न (50-60 शब्द)**: विस्तृत उत्तर
- **आशय स्पष्ट कीजिए**: वाक्यांशों की व्याख्या

### 5. 🔤 भाषा अध्ययन

- **वाक्यांशों की व्याख्या**: मुहावरों और वाक्यांशों की व्याख्या

- **क्या आप जानते हैं?**: रोचक तथ्य और जानकारी

## 🚀 सुविधाएँ

- **वाचन सुविधा**: पाठ को सुनने की सुविधा
- **शब्दार्थ हाइलाइट**: कठिन शब्दों को हाइलाइट करना

- **उपलब्धि पॉपअप**: पूर्ण किए गए मॉड्यूल के लिए प्रोत्साहन

### सुलभता सुविधाएँ

- **उच्च कंट्रास्ट**: बेहतर दृश्यता के लिए
- **फॉन्ट आकार समायोजन**: पठनीयता के लिए

### प्रतिक्रिया प्रणाली
- **तत्काल प्रतिक्रिया**: उत्तरों की तुरंत जाँच
- **विस्तृत सुझाव**: गलत उत्तरों के लिए मार्गदर्शन
- **प्रगति संकेतक**: पूर्ण किए गए अभ्यासों का दृश्य संकेत
- **स्वचालित सहेजना**: प्रगति का स्वचालित संरक्षण

```

├── css/                    # स्टाइलशीट फ़ोल्डर
│   ├── styles.css          # मुख्य स्टाइल

│   └── feedback-styles.css # प्रतिक्रिया स्टाइल
├── js/                     # JavaScript फ़ोल्डर
│   ├── main.js             # मुख्य JavaScript
│   ├── yashpal-story.js    # कहानी सामग्री
│   ├── questions.js        # प्रश्न डेटा
│   ├── activities.js       # गतिविधि फ़ंक्शन
│   ├── language-exercises.js # भाषा अभ्यास
│   ├── prereading-content.js # पूर्व-पठन सामग्री
│   ├── activity-answers.js # उत्तर कुंजी
│   └── form-enhancements.js # फॉर्म सुधार
├── simple_server.js        # स्थानीय सर्वर
└── README.md              # यह फ़ाइल
```

### तकनीकी स्टैक
- **HTML5**: सेमेंटिक मार्कअप और ARIA सुविधाएँ
- **CSS3**: फ्लेक्सबॉक्स, ग्रिड, एनिमेशन
- **JavaScript (ES6+)**: मॉड्यूलर प्रोग्रामिंग
- **Web Speech API**: वाचन सुविधा
- **Local Storage**: डेटा संरक्षण

## 🚀 स्थापना और चलाना

### आवश्यकताएँ
- Node.js (संस्करण 12 या उच्चतर)
- आधुनिक वेब ब्राउज़र (Chrome, Firefox, Safari, Edge)

### स्थापना
1. **फ़ोल्डर डाउनलोड करें**: सभी फ़ाइलें एक साथ डाउनलोड करें
2. **टर्मिनल खोलें**: फ़ोल्डर में टर्मिनल खोलें
3. **सर्वर चलाएं**: `node simple_server.js` कमांड चलाएं
4. **ब्राउज़र खोलें**: `http://localhost:3000` पर जाएं

### वैकल्पिक चलाना
यदि Node.js स्थापित नहीं है, तो आप सीधे `index.html` फ़ाइल को ब्राउज़र में खोल सकते हैं। हालाँकि, कुछ सुविधाएँ (जैसे API कॉल) काम नहीं करेंगी।
