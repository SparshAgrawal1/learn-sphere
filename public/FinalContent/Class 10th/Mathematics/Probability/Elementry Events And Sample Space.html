📋 Elementary Events

The simplest possible outcomes of an experiment that cannot be broken down further. Each elementary event represents one specific result.

Cannot be decomposed further
🌌 Sample Space

The set of all possible elementary events in an experiment. It represents the complete universe of outcomes.

S = {all possible outcomes}
➕ Probability Sum

The probabilities of all elementary events in a sample space must sum to exactly 1, representing certainty.

Σ P(elementary events) = 1
