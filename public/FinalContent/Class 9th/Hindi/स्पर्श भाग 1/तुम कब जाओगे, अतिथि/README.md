# तुम कब जाओगे, अतिथि - इंटरैक्टिव हिंदी पाठ

## परिचय

यह शरद जोशी के प्रसिद्ध व्यंग्य लेख "तुम कब जाओगे, अतिथि" पर आधारित एक इंटरैक्टिव हिंदी शिक्षण मॉड्यूल है। यह Class 9 के छात्रों के लिए डिज़ाइन किया गया है और इसमें आधुनिक वेब तकनीकों का उपयोग करके एक समृद्ध शैक्षणिक अनुभव प्रदान किया गया है।

## मुख्य विशेषताएं

### 🎯 **शैक्षणिक सुविधाएं**
- **इंटरैक्टिव पाठ पढ़ना** - ऑडियो नैरेशन के साथ
- **व्यापक प्रश्न-अभ्यास** - बहुविकल्पीय प्रश्न और मौखिक प्रश्न
- **भाषा अध्ययन** - शब्दार्थ और व्याकरण अभ्यास
- **गतिविधियां** - चर्चा प्रश्न और पाठ समझ के अभ्यास
- **प्रगति ट्रैकिंग** - छात्र प्रदर्शन और स्कोरिंग सिस्टम

### 🔊 **ऑडियो सुविधाएं**
- **Text-to-Speech** - ब्रिटिश महिला आवाज़ में हिंदी नैरेशन
- **इंटरैक्टिव ऑडियो कंट्रोल** - चालू/बंद करने की सुविधा
- **सेक्शन-वाइज़ नैरेशन** - हर भाग के लिए अलग ऑडियो
- **शब्दार्थ उच्चारण** - कठिन शब्दों की उच्चारण गाइड

### 📱 **उपयोगकर्ता अनुभव**
- **मोबाइल-ऑप्टिमाइज़्ड** - सभी डिवाइसों पर सुचारू रूप से काम करता है
- **एक्सेसिबिलिटी** - स्क्रीन रीडर और कीबोर्ड नेवीगेशन सपोर्ट
- **इंटरैक्टिव एनीमेशन** - आकर्षक विजुअल फीडबैक
- **प्रिंट मोड** - ऑफलाइन अध्ययन के लिए

### उपयोग की गई तकनीकें
- **HTML5** - सेमैंटिक मार्कअप और एक्सेसिबिलिटी
- **CSS3** - आधुनिक स्टाइलिंग और एनीमेशन
- **Vanilla JavaScript** - बिना किसी फ्रेमवर्क के शुद्ध JS
- **Web Speech API** - Text-to-Speech फ़ंक्शनैलिटी
- **localStorage** - प्रगति और प्राथमिकताएं सहेजना

## इंस्टॉलेशन और सेटअप

### आवश्यकताएं
- Node.js (वर्जन 12 या उससे ऊपर)
- आधुनिक वेब ब्राउज़र (Chrome, Firefox, Safari, Edge)

### स्थापना चरण

1. **प्रोजेक्ट डाउनलोड करें**
   ```bash
   # Git के माध्यम से
   git clone [repository-url]
   cd chapter3
   
   # या ZIP फ़ाइल डाउनलोड करके extract करें
   ```

2. **लोकल सर्वर चलाएं**
   ```bash
   # Node.js सर्वर के साथ
   node simple_server.js
   
   # या Python के साथ (अगर Python installed है)
   python -m http.server 8000
   
   # या PHP के साथ (अगर PHP installed है)  
   php -S localhost:8000
   ```

3. **ब्राउज़र में खोलें**
   ```
   http://localhost:8000
   ```

## उपयोग गाइड

### छात्रों के लिए

1. **शुरुआत करें**: "🚀 अपनी सीखने की यात्रा शुरू करें" बटन पर क्लिक करें
2. **ऑडियो चालू करें**: ऊपरी-दाएं कोने में 🔊 बटन से ऑडियो को enable करें
3. **सेक्शन नेविगेट करें**: टॉप मेन्यू से विभिन्न सेक्शन पर जाएं
4. **प्रश्न हल करें**: प्रश्न-अभ्यास में बहुविकल्पीय प्रश्नों के उत्तर दें
5. **प्रगति ट्रैक करें**: अपना स्कोर और achievement देखें

### शिक्षकों के लिए

1. **कक्षा में प्रदर्शन**: प्रोजेक्टर के साथ पूरी कक्षा को दिखाएं
2. **व्यक्तिगत अभ्यास**: छात्रों को अपने डिवाइस पर अभ्यास कराएं
3. **प्रिंट मोड**: "🖨️ प्रिंट मोड" से हार्ड कॉपी के लिए तैयार करें
4. **प्रगति मॉनिटर**: छात्रों के स्कोर और completion rate देखें
