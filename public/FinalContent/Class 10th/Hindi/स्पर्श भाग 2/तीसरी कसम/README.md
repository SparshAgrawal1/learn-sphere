# तीसरी कसम के शिल्पकार शैलेंद्र - इंटरैक्टिव हिंदी पाठ

यह एक इंटरैक्टिव हिंदी पाठ मॉड्यूल है जो प्रहलाद अग्रवाल के निबंध "तीसरी कसम के शिल्पकार शैलेंद्र" पर आधारित है।

## विशेषताएं

### 📚 मुख्य खंड
- **परिचय**: मॉड्यूल का परिचय और उद्देश्य
- **पाठ प्रवेश**: पाठ की पृष्ठभूमि और संदर्भ
- **पाठ**: मुख्य सामग्री - शैलेंद्र और "तीसरी कसम" फिल्म की कहानी
- **प्रश्न अभ्यास**: इंटरैक्टिव प्रश्न और अभ्यास
- **भाषा अध्ययन**: शब्दार्थ, मुहावरे, संधि विच्छेद
- **गतिविधियां**: आशय स्पष्टीकरण और निबंध लेखन

### 🎯 इंटरैक्टिव फीचर्स
- **ऑडियो नैरेशन**: सभी सामग्री को सुना जा सकता है
- **शब्दार्थ हाइलाइटिंग**: महत्वपूर्ण शब्दों के अर्थ
- **प्रगति ट्रैकिंग**: उपलब्धि प्रणाली और स्कोरिंग
- **रिस्पॉन्सिव डिज़ाइन**: मोबाइल और डेस्कटॉप दोनों के लिए अनुकूलित
- **प्रिंट मोड**: प्रिंटिंग के लिए अनुकूलित लेआउट

## उपयोग निर्देश

### आसान तरीका (Windows के लिए)
**सबसे आसान तरीका:** `start_and_open.bat` फ़ाइल पर डबल-क्लिक करें। यह अपने आप सर्वर शुरू करके ब्राउज़र खोल देगा।

या

`start_server.bat` फ़ाइल पर डबल-क्लिक करें, फिर ब्राउज़र में `http://localhost:8181` पर जाएं।

### मैन्युअल तरीका
```bash
# Node.js की आवश्यकता है
cd teesri-kasam-shilpkar
node simple_server.js
```

फिर अपने ब्राउज़र में `http://localhost:8181` पर जाएं।

### ⚠️ महत्वपूर्ण नोट
- हमेशा सर्वर के माध्यम से एप्लीकेशन चलाएं (http://localhost:8181)
- सीधे index.html फ़ाइल न खोलें क्योंकि कुछ फीचर्स काम नहीं करेंगे
- अगर पोर्ट 8181 पहले से इस्तेमाल में है, तो Terminal में Ctrl+C दबाकर पुराना सर्वर बंद करें
