# A Triumph of Surgery - Interactive English Lesson

This is an interactive digital lesson based on "A Triumph of Surgery" by James Herriot, designed for Class X English students.

## About the Lesson

This interactive lesson helps students engage with the story "A Triumph of Surgery" through:

- Guided reading with audio narration
- Interactive vocabulary exploration
- Comprehension questions and activities
- Grammar practice related to the story content

## Features

- **Audio narration** with a British female voice for the entire story
- **Vocabulary highlighting** with definitions
- **Interactive exercises** for comprehension and language practice
- **Progress tracking** to monitor student advancement
- **Mobile-friendly design** optimized for all devices
- **Print mode** for creating physical handouts

## Technical Requirements

- A modern web browser (Chrome, Firefox, Edge, or Safari)
- JavaScript enabled
- For full functionality, including audio narration, an internet connection is recommended

## How to Use

### Option 1: Running Locally with Node.js

1. Make sure you have [Node.js](https://nodejs.org/) installed on your computer.
2. Open a terminal/command prompt in this directory.
3. Run the command: `node simple_server.js`
4. Open your web browser and navigate to: [http://localhost:3000](http://localhost:8080)

### Option 2: Using a Local Web Server

You can use any web server to serve these files. Some options include:

- Python's built-in HTTP server:
  ```
  python -m http.server 3000
  ```
- VS Code's Live Server extension
- Any other HTTP server tool

### Option 3: Direct File Access

You can open the `index.html` file directly in a web browser, but some features like audio narration might not work properly due to browser security restrictions.

## Lesson Structure

The lesson is organized into five modules:

1. **Introduction** - Overview of the lesson
2. **Let's Begin** - Pre-reading activities and discussion prompts
3. **The Story** - The full text with audio narration and vocabulary support
4. **Reading Comprehension** - Questions to test understanding
5. **Vocabulary & Grammar** - Interactive language exercises
