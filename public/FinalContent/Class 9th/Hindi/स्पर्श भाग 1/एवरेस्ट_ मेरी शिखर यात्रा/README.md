# 🏔️ एवरेस्ट: मेरी शिखर यात्रा - इंटरैक्टिव हिंदी पाठ

बछेंद्री पाल की एवरेस्ट विजय यात्रा पर आधारित यह इंटरैक्टिव डिजिटल लर्निंग मॉड्यूल है। यह कक्षा 9वीं स्पर्श पाठ्यपुस्तक के अध्याय 2 "एवरेस्ट: मेरी शिखर यात्रा" का व्यापक डिजिटल रूपांतरण है।

## ✨ मुख्य विशेषताएं

### 📚 **व्यापक पाठ सामग्री**
- **लेखिका परिचय**: बछेंद्री पाल के जीवन और संघर्ष का विस्तृत परिचय
- **यात्रा वृत्तांत**: एवरेस्ट अभियान की संपूर्ण गाथा 6 भागों में विभाजित
- **शब्दार्थ और टिप्पणियां**: सभी कठिन शब्दों की व्याख्या के साथ

### 🎯 **इंटरैक्टिव अभ्यास**
- **मौखिक प्रश्न**: त्वरित समझ के लिए छोटे उत्तर वाले प्रश्न
- **लिखित प्रश्न**: 25-30 शब्द और 50-60 शब्द की श्रेणी में
- **आशय स्पष्टीकरण**: महत्वपूर्ण वाक्यांशों का गहन विश्लेषण
- **भाषा अध्ययन**: शब्दार्थ, विराम चिह्न और व्याकरण अभ्यास

### 🔊 **ऑडियो सुविधाएं**
- **स्वचालित वाचन**: हिंदी वाचन सहायता के साथ
- **इंटरैक्टिव ऑडियो**: पाठ के दौरान हाइलाइटिंग
- **उच्चारण गाइड**: कठिन शब्दों का सही उच्चारण
- **ब्राउज़र-अनुकूलित**: विभिन्न ब्राउज़र में अनुकूलित आवाज़

### 🎨 **आधुनिक UI/UX**
- **मोबाइल-अनुकूलित**: सभी डिवाइसों पर उत्तम प्रदर्शन
- **डार्क/लाइट थीम**: पर्वतीय थीम के साथ आकर्षक डिज़ाइन
- **प्रगति ट्रैकिंग**: रियल-टाइम प्रगति और स्कोर ट्रैकिंग
- **उपलब्धि बैज**: मॉड्यूल पूर्ण करने पर पुरस्कार

### 📝 **गतिविधियां**
- **चिंतन अभ्यास**: पाठ पर आधारित विचारशील प्रश्न
- **निबंध लेखन**: विभिन्न विषयों पर लेखन गतिविधि
- **भाषा खेल**: व्यावहारिक भाषा अभ्यास
- **स्वअध्ययन टिप्स**: बेहतर समझ के लिए अध्ययन सुझाव

## 🚀 स्थापना और उपयोग

### आवश्यकताएं
- **Node.js** (संस्करण 12 या उससे ऊपर)
- **आधुनिक वेब ब्राउज़र** (Chrome, Firefox, Safari, Edge)
- **इंटरनेट कनेक्शन** (फॉन्ट लोडिंग के लिए)

### तुरंत शुरुआत

1. **प्रोजेक्ट डाउनलोड करें**
   ```bash
   # Repository को clone करें या ZIP डाउनलोड करें
   cd everest-story
   ```

2. **सर्वर चालू करें**
   ```bash
   node simple_server.js
   ```

3. **ब्राउज़र में खोलें**
   ```
   http://localhost:8080
   ```

### वैकल्पिक स्थापना (Static Serving)
यदि Node.js उपलब्ध नहीं है:
```bash
# Python 3 के साथ
python -m http.server 8080

# PHP के साथ  
php -S localhost:8080
```

## 🔧 समस्या निवारण

### सामान्य समस्याएं

**Q: ऑडियो काम नहीं कर रहा?**
A: सुनिश्चित करें कि आपने पहले पेज पर क्लिक किया है (ब्राउज़र नीति के कारण)

**Q: कंटेंट लोड नहीं हो रहा?**
A: JavaScript सक्षम है या नहीं जांचें, और console errors देखें

**Q: मोबाइल पर टेक्स्ट छोटा दिख रहा?**
A: ब्राउज़र में zoom level बढ़ाएं या पेज को रीफ्रेश करें

**Q: सर्वर शुरू नहीं हो रहा?**
A: Port 8080 फ्री है या नहीं जांचें, दूसरा पोर्ट try करें
