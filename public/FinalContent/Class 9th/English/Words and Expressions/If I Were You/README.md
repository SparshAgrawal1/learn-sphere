# Interactive English Lesson: Identity Theft and Detectives

An interactive web-based English lesson based on Unit 9 "Identity Theft and Detectives" with comprehensive content covering detective work, identity protection, and digital safety.

## Features

- Complete interactive implementation of the textbook lesson
- Structured pedagogical approach following the original text
- Responsive design optimized for mobile and desktop devices
- Audio narration support with British female voiceover
- Interactive activities for all sections
- Progress tracking and achievements system
- Vocabulary highlighting and definitions
- Grammar exercises and language practice

## Structure

The lesson follows a comprehensive structure with six main modules:

1. **Introduction** - Welcome and overview of identity theft and detective work
2. **Let's Begin** - Introduction to digital safety and identity protection
3. **Reading Comprehension** - Two texts: "Interview with a Detective" and "Sharadindu Bandyopadhyay"
4. **Questions** - Comprehension questions for both reading texts
5. **Vocabulary & Grammar** - Vocabulary matching, grammar exercises, and language skills
6. **Activities** - Listening, speaking, writing, and creative activities

## Content Overview

### Reading Comprehension Texts

**Text I: Interview with a Detective**
- An interview with a Manhattan-based private detective
- Discussion of surveillance work and people location
- Essential skills for private investigators
- Information needed to locate missing persons
- Relationship with law enforcement
- Reality vs. fiction in detective work

**Text II: Sharadindu Bandyopadhyay**
- Biography of the Bengali writer
- Creation of the fictional detective Byomkesh Bakshi
- Comparison with other famous detectives
- Role of Ajit as narrator and companion
- Focus on truth-seeking vs. law enforcement

### Vocabulary & Grammar

- **Vocabulary Matching**: 8 key terms with definitions
- **Grammar Exercises**: Affirmative to negative sentence transformation
- **Infinitive Forms**: Completing sentences with infinitive verbs
- **Editing Exercise**: Correcting errors in a passage about Sherlock Holmes

### Activities

- **Listening Activity**: Story of King Shibi with comprehension questions
- **Speaking Activity**: Group discussion on identity theft prevention
- **Writing Activity**: Personal identity reflection (300-400 words)
- **Creative Writing**: Completing a scary story with title

## Technical Implementation

- **HTML5** for semantic structure and accessibility
- **CSS3** for modern styling, animations, and responsive design
- **JavaScript (ES6+)** for interactivity and dynamic content
- **Web Speech API** for text-to-speech narration
- **Node.js** for local development server

## Getting Started

### Prerequisites

- Node.js installed on your system
- Modern web browser with JavaScript enabled
- Internet connection for initial setup

### Installation & Setup

1. **Navigate to the project directory:**
   ```bash
   cd "Identity Theft and Detectives"
   ```

2. **Start the local development server:**
   ```bash
   node simple_server.js
   ```

3. **Open your browser and navigate to:**
   ```
   http://localhost:3000
   ```

4. **Begin the interactive lesson:**
   - Click "Start Your Learning Journey" to begin
   - Use the navigation menu to move between modules
   - Enable audio narration for the best experience

## Customization

### Voice Settings
The narration uses a British female voice by default. To customize:
- Modify voice selection in `js/main.js`
- Adjust speech rate, pitch, and volume parameters
- Add support for additional languages

### Content Updates
- Edit story content in `js/identity-detective-story.js`
- Modify questions in `js/questions.js`
- Update activities in `js/activities.js`

### Styling
- Customize colors and fonts in `css/styles.css`
- Modify responsive breakpoints for different devices
- Add new interactive elements and animations

## Troubleshooting

### Common Issues

**Audio not working:**
- Ensure browser supports Web Speech API
- Check that user has interacted with the page
- Verify microphone permissions if using recording features

**Server won't start:**
- Check if port 3000 is already in use
- Ensure Node.js is properly installed
- Verify file permissions in the project directory

**Content not loading:**
- Check browser console for JavaScript errors
- Ensure all files are in the correct directory structure
- Verify server is running and accessible

### Performance Tips

- Use a modern browser for optimal performance
- Close unnecessary browser tabs to free up memory
- Ensure stable internet connection for best experience
